# ClickHouse创建数据表与基本数据类型

## 创建数据表

```sql
CREATE TABLE [IF NOT EXISTS] [db_name.]table_name (
    name1 [type] [DEFAULT|MATERIALIZED|ALIAS expr],
    name2 [type] [DEFAULT|MATERIALIZED|ALIAS expr],
    ...
) ENGINE = engine
```

ClickHouse创建数据表的语法与标准SQL类似，但需要指定表引擎（ENGINE）。表引擎决定了数据表的特性和存储方式。

## 基本数据类型

ClickHouse提供了丰富的基本数据类型，下面介绍最常用的几种。

### 整数类型

| 类型 | 范围 | 字节数 |
| :--- | :--- | :--- |
| Int8 | [-128, 127] | 1 |
| Int16 | [-32768, 32767] | 2 |
| Int32 | [-2147483648, 2147483647] | 4 |
| Int64 | [-9223372036854775808, 9223372036854775807] | 8 |
| UInt8 | [0, 255] | 1 |
| UInt16 | [0, 65535] | 2 |
| UInt32 | [0, 4294967295] | 4 |
| UInt64 | [0, 18446744073709551615] | 8 |

### 浮点数类型

| 类型 | 说明 | 字节数 |
| :--- | :--- | :--- |
| Float32 | 单精度浮点数 | 4 |
| Float64 | 双精度浮点数 | 8 |

### 字符串类型

| 类型 | 说明 |
| :--- | :--- |
| String | 变长字符串，不限长度 |
| FixedString(N) | 定长字符串，长度为N字节 |

### 日期与时间类型

| 类型 | 说明 |
| :--- | :--- |
| Date | 日期类型，格式为 YYYY-MM-DD |
| DateTime | 日期时间类型，格式为 YYYY-MM-DD HH:MM:SS |
| DateTime64 | 高精度日期时间，支持毫秒、微秒 |

### 布尔类型

ClickHouse没有独立的布尔类型，可以使用UInt8（0或1）代替。

## 建表示例

```sql
CREATE TABLE my_table (
    id UInt64,
    name String,
    age UInt8,
    salary Float64,
    created_at DateTime
) ENGINE = MergeTree()
ORDER BY id
```

以上示例创建了一张包含多个基本数据类型的MergeTree表，以id作为排序键。
