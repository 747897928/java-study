# 数据字典

数据字典是ClickHouse提供的一种非常简单、实用的存储媒介，它以键值和属性映射的形式定义数据。字典中的数据会主动或者被动（数据是在ClickHouse启动时主动加载还是在首次查询时惰性加载由参数设置决定）加载到内存，并支持动态更新。由于字典数据常驻内存的特性，所以它非常适合保存常量或经常使用的维度表数据，以避免不必要的JOIN查询。

数据字典分为内置与扩展两种形式，顾名思义，内置字典是ClickHouse默认自带的字典，而外部扩展字典是用户通过自定义配置实现的字典。在正常情况下，字典中的数据只能通过字典函数访问（ClickHouse特别设置了一类字典函数，专门用于字典数据的取用）。但是也有一种例外，那就是使用特殊的字典表引擎。在字典表引擎的帮助下，可以将数据字典挂载到一张代理的数据表下，从而实现数据表与字典数据的JOIN查询。

# 内置字典

ClickHouse目前只有一种内置字典——Yandex.Metrica字典。从名称上可以看出，这是用在ClickHouse自家产品上的字典，而它的设计意图是快速存取geo地理数据。但较为遗憾的是，由于版权原因Yandex并没有将geo地理数据开放出来。这意味着ClickHouse目前的内置字典，只是提供了字典的定义机制和取数函数，而没有内置任何现成的数据。所以内置字典的现状较为尴尬，需要遵照它的字典规范自行导入数据，因为工作中一万年也用不到，大家知道有这么个东西即可。

# 外部扩展字典

外部扩展字典是以插件形式注册到ClickHouse中的，由用户自行定义数据模式及数据来源。目前扩展字典支持7种类型的内存布局和4类数据来源。相比内容十分有限的内置字典，扩展字典才是更加常用的功能。

# 创建字典

进入容器内部

```batch
docker exec -it clickhouse-server /bin/bash 
```

在/etc/clickhouse-server路径下创建字典\*\_dictionary.xml文件  
```xml
cat >/etc/clickhouse-server/organization_dictionary.xml<<-'EOF'
<?xml version="1.0" encoding="utf-8"?>
<dictionaries>
    <dictionary>
    <!-- 字典名称 -->
    <name>organization</name>
    <!-- 字典来源 -->
    <source>
    <!-- 通过http网络获取 -->
    <http>
    <!-- csv字典数据源地址 -->
</dictionaries> 
```

```txt
<url>http://manongbiji.oss-cn-beijing.aliyuncs.com/ittailkshow/clickhouse/download 
```

```txt
<!-- 文件格式 -->
<format>CSV</format>
</http>
</source>
<layout>
<!-- 字典布局 -->
<flat/>
</layout>
<!-- 字典结构 -->
<structure>
<!-- 定义id列 -->
<id>
<!-- 第一列名为id，类型为uint64 -->
<name>id</name>
</id>
<!-- 其他字段定义为属性列，第二字段名称为code，字符串 -->
<attribute>
<name>code</name>
<type>String</type>
<null_value/>
</attribute>
<!-- 其他字段定义为属性列，第三字段名称为name，字符串 -->
<attribute>
<name>name</name>
<type>String</type>
<null_value/>
</attribute>
</structure>
<!-- 每个300~360秒内的随机时间，重新读取字典数据，设置时间范围是为了避免瞬间多个字典同时开始加载
<lifetime>
<min>300</min>
<max>360</max>
</lifetime>
</dictionary>
</dictionaries>
EOF
```

```sql
SELECT name, type, status, key, attribute.names, attribute.types FROM system.dictionaries
```

默认字典是懒加载的，只有第一次获取字典数据时才会加载

| name | type | status | key | attribute.names | attribute.types |
| :--- | :--- | :--- | :--- | :--- | :--- |
| organization | Flat | UNLOAD | UInt64 | ['code','name'] | ['String','String'] |

利用dictGet命令获取organization字典id=1的code值  
```sql
select dictGet('organization', 'code', toUInt64(1));
dictGet('organization', 'code', toUInt64(1)) |
a0001 
```

```sql
select dictGet('organization', 'name', toUInt64(1));

```
